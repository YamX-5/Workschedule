# Yami app

Expo SDK **58** (React Native 0.88, React 19.3), Expo Router, TypeScript strict.

```
npm test                 # Jest (jest-expo)
npx tsc --noEmit         # typecheck
npx expo start --web     # web / PWA dev
npx expo run:android     # Android dev build
```

Rules live in `src/domain/` (pure TS, fully tested). Spec: `../docs/superpowers/specs/2026-11-08-yami-design.md`.
